Project Overview

What are Signal Peptides?

Signal peptides are short amino acid sequences (typically 14-30 residues) located at the N-terminus of many eukaryotic proteins. They direct nascent proteins to the endoplasmic reticulum for secretion or membrane insertion, and are cleaved off during translocation.

Biological Significance

Accurately predicting signal peptides is crucial for:

  • Understanding protein localization: Determining where proteins function within the cell
  • Characterizing secretome composition: Identifying proteins destined for secretion
  • Identifying therapeutic targets: Finding potential drug targets in secreted proteins
  • Distinguishing protein types: Separating transmembrane proteins from secreted proteins

Project Goals

  1. Develop a comprehensive dataset of positive (proteins with experimentally verified signal peptides) and negative (proteins without signal peptides) examples
  2. Apply multiple machine learning approaches to signal peptide classification
  3. Compare performance, particularly on challenging cases like transmembrane proteins
  4. Create generalizable models for broad eukaryotic protein families

Phase A: Data Collection

Raw protein data was fetched from UniProtKB using carefully designed queries to ensure high-quality positive and negative datasets.

Data Collection Strategy

Positive Dataset (Proteins with Signal Peptides)

Criteria:

  • Eukaryotic proteins only (taxonomy_id:2759)
  • Minimum length: 40 residues
  • Reviewed entries only (SwissProt)
  • Experimental signal peptide evidence
  • No fragments
  • Additional filtering: Signal peptide ≥ 14 residues and cleaved

UniProt Query:

(fragment:false) AND (taxonomy_id:2759) AND (length:[40 TO *]) AND (reviewed:true) AND (existence:1) AND (ft_signal_exp:*)

Negative Dataset (Proteins without Signal Peptides)

Criteria:

  • Eukaryotic proteins only
  • Minimum length: 40 residues
  • Reviewed entries only
  • Experimentally verified cellular localization (cytosol, nucleus, mitochondrion, plastid, peroxisome, cell membrane)
  • No signal peptides (any evidence)

Phase B: Data Preprocessing & Clustering

To eliminate sequence redundancy and ensure model generalization, MMseqs2 clustering was performed followed by careful data splitting.

Preprocessing Pipeline

Step 1: MMseqs2 Clustering

Clustering was performed on VM infrastructure to reduce sequence redundancy:

mmseqs easy-cluster input.fa cluster-results tmp \
  --min-seq-id 0.3 -c 0.4 --cov-mode 0 --cluster-mode 1
  • 30% minimum sequence identity threshold
  • 40% coverage requirement
  • Reduces 23,547 → 10,027 sequences

Step 2: Representative Selection

From each cluster, the representative sequence (highest similarity to all members) was selected:

  • Final positive dataset: 1,093 sequences
  • Final negative dataset: 8,934 sequences

Step 3: Train/Test Split

Stratified split to maintain class balance:

  • 80% training set
  • 20% test set
  • Labels: 1 for positive, 0 for negative

Step 4: Cross-Validation Preparation

Training data divided into 5 folds for cross-validation:

  • Stratified k-fold ensures similar class ratios
  • Used for hyperparameter tuning

Phase D: Von Heijne Algorithm

The von Heijne method is a traditional statistical approach for signal peptide prediction based on position-specific weight matrices (PSWM).

Algorithm Overview

Methodology

  1. Extract Training Motifs: [-13, +2] windows from positive training proteins at cleavage sites
  2. Build Position-Specific Probability Matrix (PSPM): Calculate amino acid frequencies at each position
  3. Compute Weight Matrix (PSWM): Log-odds scores comparing to background frequencies
  4. Scan N-terminus: Score all 16-residue windows in the first 90 amino acids
  5. Predict: Maximum score determines if protein has a signal peptide
  6. Threshold Optimization: F1-score maximization via Precision-Recall curve (optimal ≈ 6.73)

Mathematical Framework

Position-Specific Probability Matrix:

PSPM[aa][pos] = (count[aa] + pseudocount) / (total + background)

Position-Specific Weight Matrix:

PSWM[aa][pos] = log(PSPM[aa][pos] / background_freq[aa])

Phase E: Support Vector Machine

Advanced machine learning approach using Support Vector Machines with engineered biochemical features.

Feature Engineering

A total of 26 features were engineered from the N-terminal region (first 22 residues):

Amino Acid Composition (20 features)

Frequency of each standard amino acid in the N-terminal region

Physicochemical Properties (6 features)

  • n-region charge: Charge in first 5 residues
  • h-region hydrophobicity: Hydrophobicity in residues 5-16
  • h-region TM propensity: Transmembrane propensity in residues 5-16
  • Total N-terminal hydrophobicity
  • Total N-terminal TM propensity
  • Total N-terminal α-helix propensity

Feature Selection

Random Forest-based feature importance ranking identified top predictive features:

  • Top 1-2: Hydrophobicity and TM propensity measures
  • Selected: Top 15 features for final model
  • Validation: MCC plateaus around 10-15 features, confirming optimal selection

Model Training Pipeline

  1. Feature Scaling: StandardScaler fit on training data
  2. Hyperparameter Optimization: GridSearchCV with 5-fold cross-validation
    • Kernels tested: linear, RBF, polynomial
    • C values: [0.1, 1, 10, 100]
    • Gamma: ['scale', 'auto', 0.01, 0.1]
    • Scoring metric: F1-score
  3. Best Parameters:
    • Kernel: RBF
    • C: 10
    • Gamma: 0.1

Summary of Findings

Model Strengths

Von Heijne Algorithm:

  • Simple and interpretable position-based model
  • Good baseline performance (94% accuracy)
  • Fast prediction with no training required beyond PSWM calculation
  • Useful as reference method and for understanding biological patterns

Support Vector Machine:

  • Superior overall performance (97% accuracy, MCC: 0.847)
  • Better handling of transmembrane proteins (38% fewer false positives)
  • Robust feature engineering captures complex physicochemical patterns
  • Non-linear decision boundary (RBF kernel) models subtle distinctions
  • Fast training and prediction with interpretable features

Biological Validation

Both models confirm biological understanding:

  • Hydrophobicity is the most critical feature for signal peptide recognition
  • TM propensity helps distinguish signal peptides from membrane anchors
  • Charged n-region provides additional discriminative power
  • Feature importance rankings align with known signal peptide structure (n-region, h-region, c-region)
